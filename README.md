# Procurement & Supply Chain Performance Intelligence

AI-powered performance improvement system built with n8n to identify procurement, inventory and supplier performance opportunities and translate operational findings into financial impact.

## What it does

- Analyzes procurement price variance and annualized cost exposure
- Identifies excess inventory and working-capital tied up
- Evaluates supplier performance and operational risk
- Prioritizes improvement opportunities using deterministic analytics
- Uses Claude AI to interpret findings and generate management recommendations
- Automatically delivers performance-improvement alerts through Telegram

## Architecture

Operational Data → Validation → Analytics → Opportunity Engine → Claude AI → Management Alert

## Key Output

The system identifies opportunities such as excess inventory and supplier price variance, quantifies defensible financial exposure, prioritizes issues, and recommends actionable next steps.

## Technology

n8n · JavaScript · Claude API · Telegram Bot API

## Data

Demonstration uses a simulated automotive-component manufacturer and synthetic procurement, inventory and supplier data. Financial impacts represent identified opportunities/exposure, not realized savings.
